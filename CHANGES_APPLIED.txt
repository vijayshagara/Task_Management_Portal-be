================================================================================
TROUBLESHOOTING
================================================================================

ERROR: "getaddrinfo ENOTFOUND localhost"
FIX: Start PostgreSQL (brew services start postgresql)

ERROR: "Missing required environment variables"
FIX: Check .env has all REQUIRED variables with no spaces around =

ERROR: "invalid_grant" for Google
FIX: Generate new token at http://localhost:5000/generate-token

ERROR: Database connection failed (Attempt 3/3)
FIX: Verify database is running and credentials are correct

See SETUP_GUIDE.md for detailed troubleshooting section.
